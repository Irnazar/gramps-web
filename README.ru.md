# Gramps Web Neutral Symbols Fork

Целенаправленный форк фронтенда Gramps Web с религиозно-нейтральными генеалогическими символами.

## Обзор

Этот проект представляет собой небольшую, но продуманную модификацию интерфейса фронтенда Gramps Web.

Его цель — предложить более религиозно-нейтральный визуальный стиль для отображения генеалогических данных, особенно для символов рождения и смерти в семейных деревьях.

Генеалогия часто объединяет людей самых разных культурных и религиозных традиций в рамках одной семейной линии:

* мусульман
* христиан
* иудеев
* буддистов
* светских родственников
* семьи со смешанным вероисповеданием
* и многих других

Этот форк заменяет некоторые традиционные символы, ассоциирующиеся с конкретными религиозными традициями, на нейтральные альтернативы, полностью сохраняя исходные генеалогические данные и структуру.

Цель не в том, чтобы убрать историю или идентичность, а в том, чтобы создать интерфейс, который воспринимается уважительно и комфортно для всех.

Этот форк намеренно минималистичен. Он сосредоточен на небольшом, поддерживаемом изменении интерфейса, а не на широком расхождении с upstream-проектом.

---

## Философия

Интерфейсы программ влияют на эмоциональное восприятие.

Небольшие визуальные детали, особенно символы, связанные с жизнью, смертью и семейной историей, могут быть глубоко личными для пользователей из разных культур и традиций.

Этот форк стремится предложить:

* более спокойный и универсальный визуальный язык
* нейтральные генеалогические символы
* совместимость с разными культурными контекстами
* дружелюбный интерфейс для всех семей

---

## Цели проекта

* Сохранять совместимость с upstream Gramps Web
* Сохранять исходную модель данных
* Не изменять историческую информацию, введенную пользователями
* Сохранять изменения минимальными и удобными для поддержки
* Давать чистый и нейтральный визуальный опыт

---

## Что не является целью

Этот проект **не**:

* удаляет религиозные данные из записей
* изменяет семейную историю
* цензурирует культурную идентичность
* меняет генеалогические структуры

Меняются только некоторые визуальные символы интерфейса.

## Установка

Для локального тестирования этого форка:

```powershell
docker compose down
docker compose up --build -d
```

Эта команда собирает фронтенд из локального репозитория и запускает его вместе с образом Gramps Web API.
