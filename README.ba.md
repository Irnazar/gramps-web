# Gramps Web Neutral Symbols Fork

Gramps Web фронтендының дингә нейтраль генеалогик символдар ҡулланған маҡсатлы форкы.

## Дөйөм күҙәтеү

Был проект Gramps Web фронтенды интерфейсының бәләкәй, ләкин уйланылған үҙгәртелгән варианты булып тора.

Уның маҡсаты — генеалогик мәғлүмәттәрҙе күрһәтеү өсөн, бигерәк тә шәжәрәлә тыуыу һәм үлем билдәләре өсөн, дингә нейтральерәк визуаль стиль тәҡдим итеү.

Шәжәрә йыш ҡына бер үк ғаилә тармағында төрлө мәҙәни һәм дини мөхиттән булған кешеләрҙе берләштерә:

* мосолмандарҙы
* христиандарҙы
* йәһүдтәрҙе
* буддистарҙы
* донъяуи ҡараштағы туғандарҙы
* ҡатнаш динле ғаиләләрҙе
* һәм башҡаларҙы

Был форк ҡайһы бер традицион, билдәле бер дини традиция менән бәйле символдарҙы нейтраль альтернативаларға алмаштыра, шул уҡ ваҡытта төп генеалогик мәғлүмәтте лә, структураны ла тулыһынса һаҡлай.

Маҡсат — тарихты йә шәхси тамырҙы алып ташлау түгел, ә һәр кем өсөн ихтирамлы һәм уңайлы тойолған интерфейс булдырыу.

Был форк аңлы рәүештә минималь итеп эшләнгән. Ул киң үҙгәрештәргә түгел, ә еңел һаҡланасаҡ һәм аныҡ интерфейс үҙгәрешенә генә йүнәлтелгән.

## Философия

Программа интерфейстары эмоциональ ҡабул итеүгә йоғонто яһай.

Бәләкәй визуаль деталдәр, айырыуса тормош, үлем һәм ғаилә тарихы менән бәйле символдар, төрлө мәҙәниәт һәм традиция вәкилдәре өсөн тәрән шәхси мәғәнәгә эйә булырға мөмкин.

Был форк түбәндәгеләрҙе тәҡдим итергә ынтыла:

* тынысыраҡ һәм универсальерәк визуаль тел
* нейтраль генеалогик символдар
* төрлө мәҙәни контексттар менән яраҡлашыу
* бөтә ғаиләләр өсөн асыҡ һәм уңайлы интерфейс

## Проекттың маҡсаттары

* Upstream Gramps Web менән ярашлылыҡты һаҡлау
* Мәғлүмәттең төп моделен һаҡлау
* Ҡулланыусылар индергән тарихи мәғлүмәтте үҙгәртмәү
* Үҙгәрештәрҙе минималь һәм хеҙмәтләндереү өсөн уңайлы итеп тотоу
* Таҙа һәм нейтраль визуаль тәьҫорат тәҡдим итеү

## Маҡсат булмаған нәмәләр

Был проект **түбәндәгеләрҙе эшләмәй**:

* яҙмаларҙан дини мәғлүмәтте алып ташламай
* ғаилә тарихын үҙгәртмәй
